장면 이동 기능

장면 2로 이동하는 기능 만들기

1-1. 로켓 코드 활성화

로켓을 선택하고 코드 탭을 엽니다. ‘코블록스에서 사용’을 켜서 Rocket 오브젝트를 코드에서 사용할 수 있게 합니다.

1-2. 장면 2 생성

장면 목록에서 새 장면을 추가하고 프로젝트 장면을 선택해 장면 2를 만듭니다.

1-3. 로켓을 클릭하면 문이 열리고 장면 2로 이동하기 코딩

로켓을 클릭하면 문이 열리고, 1초 뒤 장면 2로 이동하도록 코딩합니다.

5

장면 2 구성

두번째 장면 구성하기(1)

2-1. 장면의 배경 정하기

배경 메뉴에서 수정을 누르고 우주 배경을 선택합니다.

2-2. 카메라 모드 변경하기

카메라 이동 설정을 열고 걸음에서 선회로 바꾼 뒤 메인 카메라로 사용할 수 있게 확인합니다.

2-3. 지구, 달 오브젝트 추가하기

라이브러리에서 자연, 행성 순서로 이동한 뒤 지구와 달 오브젝트를 추가합니다.

2-4. 지구와 달의 위치 지정하기

지구는 X 0, Y 0, Z 0, 크기 1.0으로 두고, 달은 X 4.5, Y 0, Z 0, 크기 0.25로 배치합니다.

6

장면 2 구성

두번째 장면 구성하기(2)

3-1. 경로 추가하기

라이브러리에서 특수, 경로 순서로 이동해 원형 경로를 추가합니다. 경로 이름은 달공전주기로 바꾸고, 위치 X 0, Y 0, Z 0, 크기 4.5로 맞춥니다.

3-2. 버디 추가하기

캐릭터에서 우주인 버디를 추가하고 위치 X -6.0, Y 1.5, Z 0.5로 배치합니다.

3-3. 두번째 카메라 추가하기

특수에서 카메라를 추가하고 위치 X -6.0, Y 6.0, Z 2.0, 회전 Z 180°로 설정합니다.

장면 1

걸음 탐사

  • 장면 1에서는 걸음으로 직접 이동합니다.
  • 방향키 또는 WASD로 탐사 공간을 둘러봅니다.
  • 궤도 연구소 이동 버튼을 찾습니다.
  • 버튼을 클릭하여 장면 2로 이동합니다.
장면 1에서는 우리가 우주 탐험가가 되어 직접 걸어 다닙니다. 이 이동 방식이 걸음입니다. 이제 궤도 연구소 이동 버튼을 눌러 관찰 장면으로 가 보겠습니다.

CoBlocks 실험

값을 바꾸어 달의 자전 주기와 공전 주기를 비교해요.

자전 각도 표시가 바뀌어요.

동시에 실행하기 공전과 자전 명령은 같은 순간에 시작해야 합니다.
  1. 공전과 자전 명령은 동시에 시작합니다.
  2. 공전 시간과 자전 시간을 같게 설정합니다.
  3. 달이 공전 1회 동안 자기 축으로 360° 회전하도록 설정합니다.
  4. 달의 표시가 지구 반대 방향으로 움직이면 시계방향과 반시계방향을 바꿉니다.
주의공전 블록과 자전 블록을 위아래로 연결하면 공전이 끝난 뒤 자전합니다. 두 블록을 반드시 ‘동시에 실행하기’ 안에 넣어 주세요.

실험 A. 공전만 하기

  • Moon을 5초 동안 Round path 경로를 따라 이동하기
  • 자전 회전 명령은 사용하지 않기

관찰 안내: 달 표면의 표시를 기준으로 방향 변화를 관찰합니다.

  • 달이 지구 주위를 한 바퀴 도나요?
  • 달 표면의 표시가 계속 지구를 향하나요?
  • 공전하는 동안 지구에서 보이는 달의 면이 어떻게 달라지나요?

실험 B. 자전과 공전 함께 하기

‘동시에 실행하기’ 안에 다음 두 명령을 배치합니다.

  • 공전: Moon을 5초 동안 Round path 경로를 따라 이동하기
  • 자전: Moon을 5초 동안 시계방향 또는 반시계방향으로 축 x:0, y:0, z:1 기준 360°만큼 회전하기

공전 1회의 시간과 자전 1회의 시간을 같게 하고 두 동작을 동시에 실행하면 달의 같은 면이 지구를 향합니다.

달 표면의 표시가 지구를 따라가지 않으면 시계방향과 반시계방향을 바꾸어 다시 실행합니다.
