투어 셔틀과 Path 준비

장면 3에 Rover와 직선 Path 1·2를 배치합니다.

Rover는 실제로 달 표면 탐사에 쓰이지만, 이번 작품에서는 상상 속 ‘정거장 투어 셔틀’로 활용합니다.

작업 순서

  1. 왼쪽 장면 목록에서 장면 3을 선택합니다.
  2. Library에서 Rover를 찾아 이동 가능한 바닥이나 통로 위에 배치합니다.
  3. Rover 이름을 ‘정거장 투어 셔틀’로 바꾸고 ‘코블록스에서 사용’을 켭니다.
  4. 직선 Path 2개를 배치하고 각각 Path 1, Path 2로 구분합니다.
  5. Rover와 Path 1·2가 CoBlocks에서 사용할 수 있는지 확인합니다.
  6. 두 Path의 화살표 방향과 높이가 자연스럽게 이어지는지 살펴봅니다.
